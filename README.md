# Project Sable

Official implementation of the paper **"Adaptive Compute Allocation for Sparse Mixture-of-Experts Inference"** (`ORL-2023-004`).

## Repository Status

**✅ Released** — The code accompanying this paper is publicly available under the Apache License 2.0.

## Abstract

We study dynamic expert routing for sparse mixture-of-experts models and propose a latency-aware allocation policy that improves throughput without sacrificing model quality.
